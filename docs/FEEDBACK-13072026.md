## Bugs

| ID      | Status | Severity | Area    | Description | Notes |
| ------- | ------ | -------- | ------- | ----------- | ----- |
| BUG-009 | OPEN   | Medium   | Invoice | A `?` appears in front of every discount amount on the invoice and receipt. | Root cause: the minus sign is U+2212, written into a monospace cell; dompdf's DejaVu Sans Mono has no glyph for it and falls back to `?`. Fixed by using an ASCII `-`. |
| BUG-010 | OPEN   | High     | Invoice | A record with many services overflows the PDF and a service block splits across the page boundary mid-way. | Root cause: one tall card per service, and no `page-break-inside` rule. Fixed by the line-item table (CHG-030) plus explicit page-break rules. |
